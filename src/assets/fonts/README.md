# Technical font assets

IBM Plex Mono, Latin normal weights 400 and 600, self-hosted WOFF2.

Source: https://github.com/fontsource/font-files/tree/main/fonts/google/ibm-plex-mono
Original project: https://github.com/IBM/plex
License: IBM-Plex-Mono-LICENSE.txt (SIL Open Font License 1.1).

Loaded by src/app/typography.css with font-display: swap. No external runtime font requests. Main UI remains the existing self-hosted Barlow font.
