# Pemetaan contoh CV ke form CMS

Acuan `CV_ATS_rian_pramudya_amanda-2.pdf`, tiga halaman. Template mengikuti urutan bagian sumber; format ATS memakai satu kolom teks yang dapat diekstrak. CV kreatif dan surat lamaran juga PDF. Data tidak ditulis ulang AI.

| Bagian contoh | Form dan field CMS |
|---|---|
| Nama dan jabatan | Profil → Nama lengkap, Headline |
| Telepon, email, LinkedIn, portfolio | Profil → Kontak dan tautan profesional |
| Professional summary | Profil → Ringkasan profesional |
| Backend, Frontend, Tools, Design, Soft Skills | Skills → Nama, Kelompok, Urutan |
| Work experience | Pengalaman → Judul jabatan, Jenis kerja, Organisasi, Mulai/Selesai, Deskripsi/Poin |
| Projects | Proyek → Judul, Peran, Repository/URL, Deskripsi/Poin, Konteks, Hasil |
| Education | Pendidikan → Institusi, Jenjang/jurusan, GPA/IPK, Tahun, Deskripsi/Poin |
| Certifications | Sertifikat → Judul, Penerbit, Tanggal, Credential ID, URL verifikasi |
| Organizational experience | Pengalaman → Jenis organisasi, Judul, Organisasi, Tahun, Deskripsi/Poin |
| Bagian tambahan opsional | Pencapaian dan Bahasa → Judul, Deskripsi, Tingkat kemampuan |
| Surat lamaran | Dokumen → Penerima, Posisi/perihal, Isi manual |

Bagian kosong dihilangkan. Data draft boleh digunakan untuk dokumen privat; publikasi dokumen merupakan persetujuan tersendiri atas seluruh isi snapshot. Telepon/email yang disembunyikan dari website dapat masuk ke dokumen privat. Admin harus meninjau PDF sebelum menerbitkannya.

Teks panjang membungkus dan melanjutkan ke halaman berikutnya. Nama teknologi/organisasi dipertahankan. Tidak menjanjikan kesamaan pixel dengan PDF contoh atau kelulusan seluruh parser ATS; urutan baca dan ekstraksi teks diuji.
