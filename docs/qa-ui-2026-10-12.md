# Audit UI dan QA — 12 Oktober 2026

## Perubahan

- Menyatukan warna tombol utama dengan token section. Override dark mode global sebelumnya menghasilkan teks gelap di atas tombol gelap pada section putih.
- Light mode mempertahankan section hitam/putih bergantian; dark mode menggunakan hitam/charcoal bergantian dengan teks dan kontrol yang sesuai.
- Memperkuat border input, pembungkusan teks panjang, grid fluid, form satu kolom di mobile, serta area scroll internal tabel admin.
- Foto profil memakai bingkai berlapis, mat, aksen bintang, dan caption terpisah agar tidak menutupi wajah.
- Memperjelas kartu proyek, timeline pengalaman, kartu kontak, dan jarak footer. Gambar pengalaman tetap tersedia pada mobile.
- Menghapus status integrasi duplikat dari ringkasan, logout duplikat dari pengaturan, dan form unggah mandiri dari Media. Status integrasi ada di pengaturan; unggahan ada pada form konten dan bisa dipakai ulang dari pustaka media.
- Mencegah filter pesan berubah saat mutasi berlangsung dan mempertahankan isian unggahan dokumen ketika gagal.
- Menghentikan petunjuk scroll karakter ketika pengunjung sudah mencapai bawah halaman.

- Akses `/admin` tanpa sesi dialihkan ke login.

## Batas pemeriksaan

- Browser otomatis tidak tersedia di sesi ini. Screenshot lintas breakpoint, overflow aktual, computed contrast, interaksi dashboard dengan sesi owner, transisi tema, dan console browser belum diverifikasi secara langsung.
- Tautan sertifikat `https://toefltestcc.com/certificate/2609312828` mendapat HTTP 403 dengan challenge Cloudflare. Perlu dibuka dalam browser manusia; respons ini tidak membuktikan tautan rusak.

- Tidak ada perubahan publikasi data CMS atau deployment dalam audit ini.
